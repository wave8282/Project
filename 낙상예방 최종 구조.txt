** 최종 구조

영상 입력
→ 관절 좌표 추출 (MediaPipe)
→ 시계열 데이터 생성 (30프레임)

→ Autoencoder
   → 이상 점수 계산

→ threshold 비교
   → 이상 여부 판단

→ LSTM
   → 낙상 여부 판단

→ 최종 판단
   → 정상 / 이상 / 낙상


**최종 판단 로직

오차 계산
→ smoothing 적용
→ threshold 비교

→ 이상이면
   → LSTM 실행

→ 최종
   정상 → 정상
   이상만 → 경고
   이상 + 낙상 → 낙상

**설계 이유 

Autoencoder → 낙상 전 이상 감지
LSTM → 낙상 확정
smoothing → 노이즈 제거
연속 프레임 → 오탐 방지
