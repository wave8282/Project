# AI 기반 예방형 낙상 감지 시스템

## 프로젝트 소개

MediaPipe Pose를 이용하여 사람의 관절 좌표를 추출하고,
LSTM 및 Autoencoder 기반 딥러닝 모델을 활용하여
낙상 및 위험 행동을 감지하는 시스템이다.

## 사용 기술

- Python
- TensorFlow
- MediaPipe
- OpenCV
- LSTM
- Autoencoder

## 개발 환경

- Google Colab
